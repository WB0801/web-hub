# 羽林之巅 · V2.2 界面与交互重构

用户确认（2026-11-26）：
- 参考 iOS 27 的界面层次、轻盈悬浮资讯与交互反馈，保留羽林之巅绿金视觉识别。
- 训练、球员、赛事等高频页面以单屏操作为先，禁止用大片无意义资讯卡片占据画面；不要以缩小文字或隐藏滚动条掩盖布局问题。
- 关键资讯常驻、补充资讯使用小型悬浮卡；复杂资料使用右侧检查器/手机底部面板。保留筛选、选中对象及原操作上下文；不堆叠弹窗。
- 界面变更不改变比赛、训练、经营算法或旧存档。每阶段完成核心测试后部署原 GitHub Pages。

## 后续独立开发主题：音乐与音效
用户反馈当前音效音量过小，UI/UX 重构结束后优先展开音频专项，不在 U1-U6 中插入新音频机制。届时先审计现有音效、音量与静音逻辑，讨论主页/管理界面/比赛音乐、击球及界面反馈、音量分组与设置、音源授权、自动播放限制、性能与离线体积，再制定分阶段实施计划。

## 后续独立功能：生涯对手（2026-11-26）
用户新增构想：为球员记录职业生涯曾遇到的对手、交手场次、胜负与胜率、对方当前世界排名等，丰富球员系统但不增加页面负担。建议以球员档案内紧凑的生涯对手入口与独立浮层展示，支持交手次数/最近交手/胜率排序，区分单打球员及双打组合；对手退役、未排名时如实显示，历史记录与当前状态分离。实际开发前核查历史战报是否完整及稳定球员 ID，不能凭空补造未保留的交手记录。具体统计范围、对手筛选及生涯宿敌规则待讨论；暂不在 U1–U6 中新增玩法，音频专项仍为 UI 完成后的下一优先主题。

发布约定：每个小阶段完成核心测试后直接合并并部署固定 GitHub Pages 地址，不必等待整个迭代完成；核实发布状态，保留版本记录及旧存档兼容性。

## 音频专项 A1–A6（2026-11-26）
目标：绿金品牌的职业体育竞技感与耐听的经营氛围；不改变模拟规则、赛事及存档。
- A1 V2.3.1：混音基础、音量独立控制、播放授权及试听，解决原固定音量偏小。
- A2 V2.3.2：细化击球、移动、触网、落地及左右声道；先以现有合成技术打磨，再评估有明确授权的录音素材。
- A3 V2.3.3：动态场馆环境、观众、关键分及不同赛级反馈。
- A4 V2.3.4：原创或明确授权配乐；菜单、经营、赛前及平滑切换。比赛默认以赛场原声为主。
- A5 V2.3.5：界面反馈、成就与冠军主题；语音属于可选功能，须验证音质及跨浏览器行为。
- A6 V2.4.0：混音平衡、长时间试听、性能、离线及跨设备验收。
每阶段独立部署，结合用户试听反馈调整。录音质量、音乐素材来源与真实听感尚待验证，不能提前承诺拟真录音品质。

### A1 V2.3.1 实施记录
- 新增独立浏览器音频偏好，迁移旧静音设置；主音量80%、比赛85%、观众40%。
- 单一 AudioContext、独立五路总线、平滑增益、动态压缩；当前仅比赛/观众音效实际接入，音乐/UI/语音预留，未声称已经实现。
- 默认比赛声源至压缩器前增益由0.33升至1.08×0.85=0.918，约2.78倍；不是实测听感响度。
- 主菜单设置、游戏设置及观赛均可打开混音检查器，含三种试听及恢复默认；仍保持4×、8×、快进静音，A2/A3再讨论加速得分音效。
- 完整脚本使用模拟 Web Audio 节点通过22项断言（旧设置、授权重试、单上下文、通道路由、静音、滑杆边界、试听等），未实际输出声音或测量设备响度。

### A2 V2.3.2 实施记录
- 原创程序合成13类球场音效，每类3个变体：8种击球、脚步、球鞋摩擦、触网、落地、出界。使用瞬态、衰减、噪声带与共鸣组合，缓存短样本，避免每帧重新生成；48kHz全部样本约591KB内存，无外部录音文件。
- 声源按球场实际屏幕投影计算左右声道，支持单打、双打、换边、接球者移动及最终落点；不支持 StereoPanner 的浏览器退回单声道。
- 1×完整自动音效，2×优先击球与回合结束，4×、8×与快进维持静音。按比分变化选择音色变体；抑制陈旧、重复音效。
- 试听入口扩充至16种选项（含左右声道、原观众音效）。
- 模拟 Web Audio 完整脚本18组断言通过，检查13类样本边界、波形有限值、5种采样率、声道、双打、缓存、静音、试听及加速。未实际试听或验证浏览器设备音质。观众仍为A1既有合成声音，A3独立打磨。

### A3 V2.3.3 实施记录
- 五档场馆声音规模：地方、区域、全国、国际巡回赛、世界大赛（Super 1000、世锦赛、年终总决赛、奥运）；依据赛事资料及名称。
- 合成双声道场馆环境音与掌声，按回合长度、胶着比分、局点、赛点及最后一分胜负选择反应；关键分降低底噪，击球仍独立控制。
- 赛前、局间保留低音量场馆环境；暂停、离场、后台、全静音、高速播放清理循环节点；缓存限制为一个环境样本及最多十个反应样本。4×/8×保持静音。
- 试听增加地方赛掌声、全国赛欢呼、世界大赛欢呼、关键分欢呼。
- 完整脚本模拟 Web Audio 25+ 项断言通过，包括5档循环样本、40种反应波形、路由、生命周期、缓存及试听。实际音色与响度、真实浏览器、线上发布状态仍需验收。未引入第三方录音，不修改生涯模拟或存档。
